# 🎭 Sentiment Analysis of Movie Reviews Using NAO Robot and Deep Learning

## 📘 Project Description

This project integrates **deep learning** and **humanoid robotics** to classify the sentiment of **movie reviews** as either **Positive** or **Negative**. The system uses LSTM model to process user speech received via the NAO robot, predicts sentiment, and responds accordingly using NAO’s speech synthesis capabilities.

---

## 🧠 Core Features

- 🗣️ Real-time speech input via NAO's dialog system
- 🧹 Text preprocessing using `NLTK`
- 📊 Sentiment classification using a trained LSTM model (Keras + TensorFlow backend)
- 🗨️ Spoken output of prediction and confidence via NAO's Text-to-Speech
